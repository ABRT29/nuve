# ☕ Nuvé Café — Site Vitrine Officiel

Site vitrine moderne, chaleureux et haute performance conçu pour **Nuvé Café**, barra de café xpress et café de spécialité situé à **El Coyol, Veracruz (Mexique)**.

Développé sur la base exacte de l'identité visuelle extraite des photos réelles (palette de couleurs, typographie avec empattements raffinée, logo vectoriel avec tasse, nuage de vapeur et branches botaniques, carte complète et réseaux sociaux).

---

## 🎨 Identité Visuelle & Charte Graphique

- **Palette de couleurs :**
  - **Crème doux / Écru** (`#F7F4EE`, `#F1EBE1`, `#FAF7F2`) : Évoque la mousse de lait texturée et la douceur du lieu.
  - **Expresso profond** (`#2E1D15`, `#1E120D`) : La richesse et l'intensité du grain de café torréfié.
  - **Caramel / Terracotta** (`#C47C49`, `#D9905E`) : Accent chaleureux et gourmand pour les boutons et badges.
  - **Vert sauge / Botanique** (`#53644B`, `#EAF0E8`) : Rappel des feuilles et cerises du caféier représentées sur la devanture.
- **Typographies :**
  - Titres & Identité : *Playfair Display* (serif élégant et chaleureux).
  - Sous-titres & Badges : *Plus Jakarta Sans* (sans-serif moderne avec espacement marqué).
  - Touches manuscrites : *Caveat* (esprit fait maison avec amour).
- **Logo SVG Haute Définition :**
  - Tasse de café minimaliste avec anse.
  - Vapeur stylisée en volute de nuage (*nuvé* = *nube*).
  - Éclat `+` au sommet et petit cœur terracotta.
  - Versions adaptées : badge circulaire officiel, en-tête horizontal, et bannière avec branches botaniques.

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 18+ ou 20+

### Installation & Développement
```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement local
npm run dev
```

### Production Build
```bash
# Vérifier les types et compiler pour la production
npm run build
```

## ☁️ Déploiement sur Vercel

Le projet est configuré pour un déploiement instantané "Zero-Config" sur Vercel :

### Option 1 : Déploiement via Vercel CLI
```bash
npx vercel
```

### Option 2 : Déploiement via GitHub / GitLab
1. Poussez ce dépôt sur GitHub ou GitLab.
2. Allez sur [vercel.com/new](https://vercel.com/new).
3. Importez le dépôt : Vercel détecte automatiquement la configuration Vite (`dist` et `npm run build` définis dans `vercel.json`).
4. Cliquez sur **Deploy** !
